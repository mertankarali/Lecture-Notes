    A circuit has $2b$ unknowns: $b$ more equations come from the elements.
  \end{center}
  \vfill
\end{frame}

%--------------------------------------------------------------
\begin{frame}{Why this lecture?}
  \vfill
  \begin{itemize}\itemsep10pt
    \item \textbf{So far:} KCL and KVL, written for \alert{any} elements.
    \item<2-> \textbf{Now:} \alert{LTI resistive circuits}, where every equation is
      \alert{linear} and \alert{algebraic}.
    \item<3-> \textbf{Two ways to solve:} \alert{transform} the circuit into a simpler one,
      or write its equations \alert{as it is}.
    \item<4-> \textbf{This lecture --- transform:} replace a part by a source, or by a simpler
      part with the same terminal behaviour
      \begin{itemize}\itemsep2pt
        \item substitution theorem, equivalent one-ports
        \item series and parallel connections, source transformation
      \end{itemize}
    \item<5-> \textbf{Later --- the circuit as it is:} node voltage and mesh current
      analysis
  \end{itemize}
  \vfill
\end{frame}

          \draw (1.3,0) to[C, l=$C$] (1.3,1.4);
        \end{tikzpicture}\\[4pt]
        \raggedright
        \alert{Dynamic} if it contains \alert{at least one} dynamic element: an $L$ or a $C$.\\[4pt]
        Otherwise \textbf{resistive}.
      \end{block}}
    \end{column}
  \end{columns}
  \vfill
  \onslide<4->{%
  \begin{center}
    \textbf{LTI resistive circuit} = \textbf{linear} + \textbf{time-invariant} +
    \textbf{resistive}:\\[3pt]
    apart from the independent sources, \alert{every element} is linear, time-invariant and
    resistive.
  \end{center}}
  \vfill
\end{frame}

\begin{frame}{What varies in time?}
  \vfill
  \begin{center}
    In \alert{every} circuit $\Vcol{v(t)}$ and $\Icol{i(t)}$ are functions of time.
    The question is whether the \alert{element law} changes with time.
  \end{center}
  \vfill
  \begin{columns}[t,onlytextwidth]
    \begin{column}{0.48\textwidth}
      \begin{block}{Time-invariant resistor}
        \centering
        $\Vcol{v(t)} = R\,\Icol{i(t)}$\\[4pt]
        the same rule at every instant
      \end{block}
    \end{column}
    \begin{column}{0.48\textwidth}
      \onslide<2->{%
      \begin{block}{Time-varying resistor}
        \centering
        $\Vcol{v(t)} = R(t)\,\Icol{i(t)}$\\[4pt]

      \end{block}}
    \end{column}
  \end{columns}
  \vfill
  \begin{center}
    \onslide<3->{Linear or nonlinear is also a property of the element law:
      $\Vcol{v} = R\Icol{i}$ is linear, a diode law is not.}
  \end{center}
  \vfill
\end{frame}

\begin{frame}{What we gain}
  \begin{block}{Always --- no assumption on the elements}
    \centering
    KCL and KVL are \alert{linear} for \alert{every} circuit: they come from the graph alone.
  \end{block}
  \vspace{6pt}
  \onslide<2->{%
  \begin{block}{Because the circuit is LTI resistive}
    Every element equation is \alert{linear} and \alert{algebraic}, with no derivative:
    \[
      \Vcol{v} = R\Icol{i} \ \ \text{(resistor)}, \qquad
      \Vcol{v} = \mu\Vcol{v_x}, \ \ \Icol{i} = g\Vcol{v_x}, \ \dots \ \
      \text{(dependent sources)}
    \]
  \end{block}}
  \vfill
  \begin{itemize}\itemsep6pt
    \item<3-> Time enters only through the values of the \alert{independent sources}.
    \item<4-> So at each instant the circuit is solved like a circuit with
      \alert{constant} sources: $2b$ linear algebraic equations.
  \end{itemize}
  \vfill
\end{frame}

\begin{frame}{The substitution theorem}
  \vfill
  \begin{center}
  \begin{tabular}{@{}c@{\hspace{4mm}}c@{\hspace{4mm}}c@{}}
  \begin{tikzpicture}[scale=0.8]
    \pairbox{$N_1$}{$N_2$}
  \end{tikzpicture} &
  \onslide<2->{\begin{tikzpicture}[scale=0.8]
    \subsbox{0}
  \end{tikzpicture}} &
  \onslide<3->{\begin{tikzpicture}[scale=0.8]
    \subsbox{1}
  \end{tikzpicture}}\\[2pt]
  (I) & \onslide<2->{(II)} & \onslide<3->{(III)}
  \end{tabular}
  \end{center}
  \vfill
  \only<1>{\begin{center}A circuit cut into two parts, joined at the terminals $a$, $b$.\\
    $\Icol{i}$: current from $N_1$ into $N_2$ \quad $\Vcol{v}$: voltage between $a$ and $b$
  \end{center}}%
  \only<2>{\begin{center}Replace $N_2$ by a voltage source with $\Vcol{v_s(t)} = \Vcol{v(t)}$
    \dots\end{center}}%
  \only<3>{\begin{center}\dots\ or by a current source with $\Icol{i_s(t)} = \Icol{i(t)}$.
    \end{center}}%
  \only<4->{%
  \begin{block}{Substitution theorem}
    No branch voltage or branch current inside $N_1$ changes. An observer inside $N_1$
    \alert{cannot tell} (I), (II) and (III) apart.
  \end{block}}
  \vfill
\end{frame}

%--------------------------------------------------------------
\begin{frame}{Why does it work?}
  \vfill
  \begin{itemize}\itemsep10pt
    \item The equations inside $N_1$ (KCL, KVL, element equations) do \alert{not} change.
    \item<2-> $N_1$ meets the rest only through $\Vcol{v}$ and $\Icol{i}$.
    \item<3-> The source fixes one of them at the value it had in (I).
    \item<4-> So the solution of (I) still satisfies every equation of (II) and (III).
    \item<5-> $N_2$ can be \alert{anything}, even nonlinear: only its port values matter.
  \end{itemize}
  \vfill
  \onslide<6->{%
  \begin{block}{One condition}
    The new circuit must have a \alert{unique} solution.\\[3pt]
    Example: $N_1$ a single current source and $N_2$ replaced by a current source
    $\Rightarrow$ $\Vcol{v}$ undetermined.
  \end{block}}
  \vfill
\end{frame}

\begin{frame}{Ports and one-ports}
  \begin{block}{Port, one-port}
    A pair of terminals is a \alert{port} if the current entering one terminal equals the
    current leaving the other. A \alert{one-port} is a circuit, or a circuit element, with one
    pair of terminals accessible from outside.
  \end{block}
  \vfill
  \begin{columns}[c,onlytextwidth]
    \begin{column}{0.36\textwidth}
      \centering
      \begin{tikzpicture}[scale=1.05]
        \oneport{$N$}
      \end{tikzpicture}
    \end{column}
    \begin{column}{0.62\textwidth}
      \begin{itemize}\itemsep8pt
        \item<2-> A one-port is always a port: KCL on a closed surface around $N$.
        \item<3-> $\Icol{i}$ enters the $+$ terminal of $\Vcol{v}$.
        \item<4-> The relation between $\Vcol{v}$ and $\Icol{i}$ is the
          \alert{$i$--$v$ characteristic}, e.g.\ $\Vcol{v} = R\Icol{i}$ for a resistor.
      \end{itemize}
    \end{column}
  \end{columns}
  \vfill
\end{frame}

%--------------------------------------------------------------
\begin{frame}{Equivalent one-ports}
  \begin{block}{Equivalent one-ports}
    $N_1 \equiv N_2$ if they have the \alert{same $i$--$v$ characteristic} at their
    terminals.
  \end{block}
  \vfill
  \begin{center}
  \begin{tabular}{@{}c@{\hspace{12mm}}c@{}}
  \begin{tikzpicture}[scale=0.9]
    \pairbox{$N_0$}{$N_1$}
  \end{tikzpicture} &
  \begin{tikzpicture}[scale=0.9]
    \pairbox{$N_0$}{$N_2$}
  \end{tikzpicture}
  \end{tabular}
  \end{center}
  \vfill
  \begin{center}
    \onslide<2->{For any $N_0$: every branch voltage and current inside $N_0$ is the
      \alert{same} in both.\\[4pt]}
    \onslide<3->{Why: the equations are those of $N_0$ plus the $i$--$v$ characteristic at the
      port.\\[4pt]}
    \onslide<4->{Inside $N_1$ and $N_2$ the branch values \alert{may differ}.}
  \end{center}
  \vfill
\end{frame}

\begin{frame}{Source transformation}
  \begin{columns}[c,onlytextwidth]
    \begin{column}{0.5\textwidth}
      \begin{block}{Source transformation}
        The two one-ports are equivalent if
        \[
          R_1 = R_2 = R \qquad\text{and}\qquad v_s = R\, i_s .
        \]
      \end{block}
      \vspace{8pt}
      \onslide<2->{Open circuit ($\Icol{i} = 0$): $\Vcol{v} = v_s$.\\[4pt]}

\begin{frame}{Solving LTI resistive circuits}
  \vfill
  \begin{itemize}\itemsep10pt
    \item Series and parallel connections and source transformations simplify
      \alert{many} circuits, but not all.
    \item<2-> Two methods write the equations of the circuit \alert{as it is}, without
      transforming it, and work for \alert{every} LTI resistive circuit:
      \begin{enumerate}\itemsep4pt
        \item \alert{node voltage analysis}: the $n - 1$ node voltages are the unknowns;
        \item \alert{mesh current analysis}: the $b - n + 1$ mesh currents are the unknowns.
      \end{enumerate}
    \item<3-> Both start from the matrices met earlier ($A$, $M$), now with linear element
      equations.
  \end{itemize}
  \vfill
\end{frame}

%--------------------------------------------------------------
\begin{frame}{Summary}
  \vfill
  \begin{itemize}\itemsep7pt
    \item \alert{LTI resistive}: apart from the independent sources (external inputs), every
      element is linear, time-invariant and memoryless, so all equations are linear and
      algebraic.
    \item \alert{Substitution}: replace $N_2$ by a voltage source $\Vcol{v_s} = \Vcol{v}$ or a
      current source $\Icol{i_s} = \Icol{i}$; nothing changes inside $N_1$.
    \item \alert{Equivalent one-ports}: the same $i$--$v$ characteristic; the rest cannot
      tell them apart.
    \item Series: $R_{eq} = \sum R_j$, $v_{s,eq} = \sum v_{sj}$. \ Parallel:
      $G_{eq} = \sum G_j$, $i_{s,eq} = \sum i_{sj}$.
    \item \alert{Source transformation}: $v_s$ with series $R$ $\equiv$ $i_s = v_s/R$ with
      parallel $R$.
  \end{itemize}
  \vfill
\end{frame}
